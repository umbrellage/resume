# 隐藏预览模式下的内容面板设计

## 概述

隐藏预览后，A4 空白区域通过下拉切换展示四个功能面板，提升编辑效率。

## 布局结构

- 控制栏右侧增加下拉选择器，默认选中「统计」面板
- 隐藏模式下，空白区域显示选中面板内容
- 面板内容居中展示，宽度适配 A4 区域

## 四个面板

### 1. 简历统计面板
- 总字数统计（姓名、标题、各项内容）
- 已完成 section 数量
- 各 section 条目数量（教育经历 x2、工作经历 x1 等）

### 2. 模板切换面板
- 四个模板缩略图（Classic、Minimal、Intern、FreshGrad）
- 当前选中模板高亮
- 点击切换模板

### 3. 快捷操作面板
- 导出 PDF
- 发送邮箱
- 复制简历链接
- 全屏编辑模式

### 4. 大纲导航面板
- 简历结构树（个人信息、教育经历、工作经历等）
- 点击跳转编辑对应区块
- 已填内容高亮

## 数据依赖

- 统计和大纲：直接读取 `useResumeStore`
- 模板切换：复用已有 `setTemplate` action
- 快捷操作：复用 EditorPage 已有的 handleDownload/sendEmail

## 实现要点

- 新增 `hiddenPanel` state 到 PreviewPanel，默认为 'stats'
- 控制栏增加下拉选择器
- 隐藏模式下渲染选中面板组件
- 面板组件作为独立子组件，保持单一职责
